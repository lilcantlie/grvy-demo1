# iPhone Fanfic Simulator

A customizable, browser-based iPhone-style fanfic simulator built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. For best results, use a local static server or GitHub Pages.

## Deploy to GitHub Pages
Upload the contents of this folder to the root of your repository (not the ZIP file), then enable GitHub Pages from the repository settings if it is not already enabled.

## Project structure
- `index.html`: page structure and app shell
- `style.css`: layout, styling, and responsive behavior
- `app.js`: simulator navigation, passcode, chat content, notifications, and app interactions
- `assets/photos/`: wallpaper and Photos gallery images

## Customize
- Update chat conversations and app content in `app.js`.
- Replace or add gallery photos in `assets/photos/`, then update the `IMAGES` list in `app.js`.
- Adjust colors, spacing, and responsive styling in `style.css`.
